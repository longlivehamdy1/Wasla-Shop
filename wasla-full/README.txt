Wasla Shop - نسخة Vercel (النسخة الآمنة + كل الميزات)
======================================================

اللي في الـ zip:
- index.html        : الموقع
- api/[...path].js  : السيرفر (دالة واحدة لكل الـ API)
- api/data.js       : بديل آمن للملف القديم (لو ارتفع فوق الـ repo القديم)
- lib/core.js       : منطق السيرفر (دخول، صلاحيات، مزامنة، نسخ احتياطي، تتبع)
- vercel.json, package.json

الرفع (لو عندك المشروع شغال على فيرسل بالفعل)
-----------------------------------------------
1) ارفع كل الملفات دي على نفس الـ GitHub repo (Wasla_shop) فوق القديم.
   (الملف القديم api/data.js هيتبدل بالجديد، ومحتاجش تمسح حاجة.)
2) فيرسل هيعمل Deploy لوحده.
3) أول ما تفتح الموقع، بياناتك القديمة (طلبات، عملاء، شات، صور) بتتنقل لوحدها
   من قاعدة البيانات القديمة، والباسوردات بتتشفر. مفيش حاجة تنقلها بإيدك.
   الحسابات اللي باسورداتها كانت 123 هتطلب تغيير الباسورد أول دخول.

الرفع من الصفر (مشروع جديد)
-----------------------------
1) ارفع الملفات على repo في GitHub، وفي vercel.com: Add New > Project واختار الـ repo.
2) بعد أول Deploy: تبويب Storage > Create Database > اختار Upstash (Redis).
   - اختار المنطقة Frankfurt (eu-central-1) لأنها الأقرب لمصر وللدالة (fra1).
   - اربطه بالمشروع (بيضيف متغيرات البيئة KV_REST_API_URL و KV_REST_API_TOKEN لوحده).
3) Deployments > Redeploy.
4) ادخل بـ manager / 123 وغيّر الباسورد (هيطلب منك).

التكلفة وحدود الخطة المجانية
------------------------------
- Upstash المجاني: 500 ألف أمر في الشهر. الموقع مضبوط يوفّر: كل مزامنة فاضية = أمر واحد،
  والمزامنة بتهدى لوحدها لما محدش بيستخدم الصفحة. تقريبًا 5 موظفين طول اليوم = حوالي 300 ألف أمر.
  لو عديت الحد، الخطة المدفوعة بتحسب 0.20$ لكل 100 ألف أمر (يعني قروش).
- فيرسل بيحد حجم الطلب بـ 4.5MB: الصور بتتضغط تلقائي (حد أقصى 5 صور للجهاز).
- خطة فيرسل المجانية (Hobby) مكتوب فيها إنها للاستخدام الشخصي غير التجاري. لمحل شغال فعلاً الأنسب
  خطة Pro، أو استخدم النسخة بتاعت Google Cloud Run.

الأمان
-------
تسجيل الدخول من السيرفر، كلمات المرور مشفرة، كل دور بياخد بياناته بس، حماية من حقن الأكواد،
وحد لمحاولات تخمين الباسورد. نسخة احتياطية تلقائية يوميًا (آخر 30 يوم) ومعاها استرجاع من:
مدير > الإعدادات.

ملاحظات
--------
- لو سجّلت دخول الحساب من جهاز تاني، الجهاز الأول بيخرج (ممكن ياخد لحد دقيقتين).
- التصدير اليدوي بيحط الصور لحد ~3MB (حد رد فيرسل)؛ النسخ الاحتياطية اليومية بتحتفظ بكل حاجة.
- الطلبات القديمة مفيهاش تواريخ دقيقة، فالتقارير الزمنية بتظبط مع الطلبات الجديدة.
